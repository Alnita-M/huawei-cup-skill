# 华为杯解题 Skill v1.0（图像视觉类 + 数据预测类）

> 由 2017–2021 华为杯 11 道赛题"盲做→对照→差距分析"蒸馏，经 2022–2023 四题盲测（方法论对齐度均值 **83.5%**，全部 ≥70% 闸门）与 2024–2025 四题实战联网评估（F01 **82/90/88/85**、F02 **84/87/86/86**、F03 ≈0.80、F04 ≈0.84）后定型的数学建模解题方法论。

一句话：拿到题面后 **先分类定方法论，再按决策树逐点取法，全程规避已证陷阱**——"由题目正向推导出答案"，而非知识罗列。

## 安装

**Hermes Agent**：把整个文件夹放入 `~/AppData/Local/hermes/skills/huawei-cup-math-modeling/`（frontmatter 已合规，自动识别）。

**Codex CLI**：
```bash
codex skill add https://github.com/Alnita-M/huawei-cup-skill.git
# 使用：@huawei-cup-math-modeling 帮我解 XXX 题
```

**手动**：直接按 `SKILL.md` 章节顺序使用即可（纯 Markdown + Python 模板，零平台依赖）。

## 用法（六步）

```
第 0 步 公式/表格为图片先 OCR 复原；多附件题先读说明文件确认数据形态
第 1 步 第二节分类器逐小问定类（图像视觉 / 数据预测 / 混合 / 优化）
第 2 步 对应决策树逐点取法（每点带溯源编号）
第 3 步 顶层 6 步：问题重述 → 假设 → 逐问建模 → 求解 → 验证 → 自评
第 4 步 对照陷阱库 48 条逐条防坑
第 5 步 代码骨架套 templates/
第 6 步 套论文模板写作；提交前跑 24 项自检清单
```

**强制项**（实战教训）：即使无数据附件，也用合成数据（注明"合成"）跑通全流程，交付**带数字的结果表与图**。

## 适用范围

✅ 图像/视频/信号中提取、识别、匹配、测量、估计；表格/时序数据回归、分类、预测、筛选、优化、评估；两类混合。
❌ 纯运筹/纯组合优化题（无数据建模环节）、纯物理公式推导题、纯定性分析题。

## 溯源与边界（诚实声明）

- 全部规则带溯源编号（D01–D11 蒸馏题 / H01–H04 盲测题 / F01–F04 实战题）；"待核实"内容不作规则依据。
- 华为杯不发布官方标准答案，权威参考为获奖优秀论文（cpipc.acge.org.cn、zhanwen/MathModel 汇总）；部分年份论文全文未公开，评估按"部分证据"降级，详见各评估报告。
- 数据附件未随仓提供；解答为"方法+公式+预期实现与验证方案"层级，参赛时须自行下载赛题附件并回填数值。
