## 用法（第 0 → 7 步，与 `SKILL.md` 第四节一致）

```text
第 0 步    公式/表格为图片先 OCR 复原；多附件题先读说明文件确认数据形态
第 0.5 步  数据形态直读（类型体系/像素含义/年份截尾/缺测坐标），开 MECH/INN 台账
第 1 步    第二节分类器逐小问定类（图像视觉 / 数据预测 / 混合）
第 2 步    对应决策树逐点取法（每点带溯源编号）
第 3 步    假设与逐问建模（每问方法卡：决策点编号 + 溯源）
第 4 步    求解与验证（数值结果表 + 图 + 验证协议）
第 5 步    诚实性机制化与失败案例分析
第 6 步    三盲评自评 + 论文写作；提交前跑 25 项自检清单
第 7 步    台账收口 + continuation state（跨会话续跑）
```

**强制项**（实战教训）：即使无数据附件，也用合成数据（注明"合成"）跑通全流程，交付**带数字的结果表与图**——"无附件不交付数值"是实测评分的系统性失分点。

## 适用范围

✅ 图像/视频/信号中提取、识别、匹配、测量、估计；表格/时序数据回归、分类、预测、筛选、优化、评估；两类混合。
❌ 纯运筹/纯组合优化题（无数据建模环节）、纯物理公式推导题、纯定性分析题。

## 溯源与边界（诚实声明）

- 全部规则带溯源编号：**D01–D11**（2017–2021 蒸馏题）、**H01–H04**（2022–2023 盲测题）、**F01–F04**（2024–2025 实战题）；机制标签 `[M]`=流程层机制吸收（v1.1）、`[C]`=同题对比实证（v1.1）、`[E]`=真实数据实跑实证（v1.2）、`[G]`=官方附件无标注实战实证（v1.3）。"待核实"内容不作规则依据。
- **v1.4 为一致性修订版**：不新增方法论结论、不改任何决策点与陷阱规则，只修文档与内容对不上的地方（详见 `CHANGELOG.md` v1.4）。
- 华为杯不发布官方标准答案，权威参考为获奖优秀论文（cpipc.acge.org.cn、zhanwen/MathModel 汇总）；部分年份论文全文未公开，评估按"部分证据"降级，详见各评估报告。
- 数据附件未随仓提供；本仓解答为"方法+公式+预期实现与验证方案"层级，参赛时须自行下载赛题附件并回填数值（2025C 官方附件的实做结果已内化为 `[G]` 层规则，原始数据不随仓分发）。
