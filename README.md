# 华为杯解题 Skill v1.6（图像视觉类 + 数据预测类）

> 由 2017–2021 华为杯 11 道赛题「盲做→对照→差距分析」蒸馏，经 2022–2023 四题盲测（方法论对齐度均值 **83.5%**，全部 ≥70% 闸门）、2024–2025 四题实战联网评估（F01 **82/90/88/85**、F02 **84/87/86/86**、F03 ≈0.80、F04 ≈0.84），以及两轮真实数据实跑（crack-seg 4029 张裂缝分割 `[E]`；2025C 官方附件无标注裂隙识别 `[G]`）迭代定型。

## 用法（与 `SKILL.md` 第四节的步骤编号严格一致）

```text
第 0.5 步  数据形态直读（多附件题强制）：类型体系/像素含义/年份截尾/缺测坐标
第 1 步    问题重述：题面数字逐条翻译为口径；参考文献方法族聚类；开 MECH/INN 台账
           （题面公式为图片/OMML 时先做 PDF/OCR 复原——这是本步内的一项，不单列步骤）
第 2 步    建立假设：数据类 / 约定类 / 几何类，每条标结论敏感性
第 3 步    逐问建模：第二节分类器给每个小问定类（图像视觉 / 数据预测 / 混合）
           → 第三节对应决策树逐点取法（每点带溯源编号）
第 4 步    求解：按模型形式定求解器层级，优先线性化/解析化
第 5 步    验证：内部一致性 + 外部独立真值 + 无真值三层自检；防泄漏
第 6 步    自评：三盲评 scorecard（席 A/B/C）+ 论文写作；提交前跑 25 项自检清单
第 7 步    工程化收尾：台账收口 modeled/descoped + continuation state（跨会话续跑）
```

> **易混点（v1.5.2 更正）**：本文件此前把「分类器定类」写成「第 1 步」，与 `SKILL.md` 第四节
> （第 1 步 = 问题重述、第 3 步 = 逐问建模）**编号错位**，已按主文件对齐。

**强制项**（实战教训）：即使无数据附件，也用合成数据（注明"合成"）跑通全流程，交付**带数字的结果表与图**——"无附件不交付数值"是实测评分的系统性失分点。

## 三侧协作（v1.5.2 新增，详见 `SKILL.md` 第七节）

拿到题后可启用三侧协作模式：**Qwen 侧 = 建模与数据（口径/常数）权威；助手侧 = 实现与账本权威；用户侧 = 终审权威**。

- **七阶段 × 六接触点**：S0 入库 → S1 盲态并行 → S2 交叉比对 → S3 分歧裁决 → S4 规格冻结 → S5 实现产出 → S6 双层核对 → S7 交付
- **反谄媚核对**：盲态先做 + 强制红队（禁止赞同语）+ 分歧裁决阶梯 L1–L6（禁止投票平均）
- **双账本防漂移**：spec 层（常数/阈值/口径，Qwen 权威，记 `口径表.md`）与 result 层（数据算出的结果，代码权威，记 `registry.json`）分离记账
- **通道**：`qoderclicn`（Qoder CN CLI）+ `Qwen3.8-Max`，走既有 Qoder 订阅，无需独立 API Key；适配器与协议见工作目录 `huawei-cup-workflow/`

## 适用范围

✅ 图像/视频/信号中提取、识别、匹配、测量、估计；表格/时序数据回归、分类、预测、筛选、优化、评估；两类混合。
❌ 纯运筹/纯组合优化题（无数据建模环节）、纯物理公式推导题、纯定性分析题。
