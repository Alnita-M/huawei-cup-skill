## 二、使用流程建议（管线编排顺序）

```
数据到手 → predictor_data_audit（体检）→ predictor_feature_engineering（筛特征）
        → predictor_modeling_validation（建模+防泄漏验证）→ uncertainty_optimization（优化/区间）
图像视觉题 → image_preprocess（预处理）→ image_features_modeling（特征/模型/评估）
谱估计与双碳核算类题从新模板起步：
谱估计/阵列类题 → signal_processing（定阶→子空间→解相干→自校准→CS）
双碳核算/情景类题 → emissions_ledger（核算→勾稽→缺口标注）→ scenario_planner（对标→灵敏度→对比表）
临床纵向类题 → clinical_longitudinal（LME→分组 CV→有序结局→混杂控制）
时空/短临外推预报类题 → ensemble_forecast（成员生成→分位聚合→区间输出→可靠性/平流检查）
分割/像素级标注类题 → polygon_to_mask（口径声明+占比检查）→ 训练/推理 → segmentation_eval（双口径指标+分布+最差样本归因）
```

## 三、跨题复用要点（蒸馏出的共性骨架）

1. **矩阵分解一族（2017D）**：背景低秩+前景稀疏 = 监控视频题的万能骨架，
   RPCA 的 ADMM 三步迭代（SVT→软阈值→乘子上升）在 `image_preprocess.rpca_ialm` 已完整给出，
   动态背景升级为三分量（加权 Frobenius 噪声，N 更新有闭式解）。
2. **旋转不变特征（2019B）**：星图识别的一切特征必须是 SO(3) 不变量；
   角距+星等差双属性哈希砍碰撞、三角形闭环去歧义、姿态全局投影验证一票否决 —— 三层递进。
3. **姿态/几何闭合公式（2019B/2019C）**：三锥交汇 `U d = c` 线性解、
   交比测高 `H = h_c(1−CR)`、`D = −h·cotα` —— 平面几何测量题直接套。
4. **光学物理（2020E）**：Koschmieder `MOR = ln(1/ε)/σ ≈ 2.996/σ` + 暗通道先验
   `t(x)=1−ω·min(I/A)` —— 能见度/去雾题的标准双路线，注意 ε 口径（0.05 vs 0.02 RVR）。
5. **降维红线（2020B/2021D 双题印证）**：选原始变量子集 ≠ PCA 压缩；
   PCA 只许诊断（本征谱/有效秩），交付必须是可解释的原列 —— 多篇获奖论文同此口径。
6. **防泄漏（2020B/2021B/2021D 三题印证）**：特征筛选、SMOTE、调参一切数据依赖量
   折内完成；时序预测附加「特征时间戳 ≤ 起报时刻」因果检查 + 滚动重训。
   同族纪律延伸（2023E）：患者级数据 GroupKFold 按 ID 分组，个体内相关不得跨折。
7. **优化收尾模板（2020B/2021D 同构）**：前问模型当代理 → 分位数/附件定可行域 →
   启发式搜索（DE/PSO/GA 多起点）→ 约束罚函数/ε-约束 → 输出达标集 + 稳健复核
   （蒙特卡洛扰动 + 第二种方法复核）——反向设计题的满分闭环。
8. **误差诚实（2018D/2019B/2020E）**：复差指标替代单看 ΔH/Δg、选星用 |det U|、
   外推给置信区间 —— 评审最看重的不只是方法，还有误差结构分析。
9. **定阶-解相干纪律（2022A）**：子空间法三前提一条都不能少 —— MDL/AIC 定阶、
   信源数 < 阵元数、相干源先平滑解相干；SVD 取噪声子空间优于显式 X·Xᴴ。
10. **台账可勾稽（2023D）**：核算处处可勾稽（分项和=总量），GWP 版本口径先锁定
    再核算；情景对标看「首达年 + 累计缺口」双量，双控题两条约束同时达标才算数。
11. **有序与混杂（2023E）**：有序结局用累积链接/取整回归 + QWK（不弃顺序信息）；
   疗效对比必做倾向评分 IPW 且报加权 SMD 平衡检验（<0.1 才可接受）。
12. **集合预报（2025D）**：短临外推的不确定性量化优先「集合」形态——幅度
    ±10–20%/方向 ±10° 扰动（或初值/模型多成员）→ P10/P50/P90 分位聚合，
    比单一预测区间可视化友好、直接服务下游决策（航路/阈值稳健性）；
    区间必须做可靠性检验（经验覆盖率 vs 名义水平 + PIT 直方图 + spread-skill），
    配半拉格朗日平流一致性检查（R4 时间维平滑的物理自检），
    不默认集合优于去相关尺度/区间法，需同协议对照。
13. **分割评估纪律（2025C Q1 实测 [E]）**：口径三连声明——① 标注转 mask 的**转换口径**
    （fill vs stroke，实测差 0.41 pt）；② 指标的**公式与聚合层级**（批级 vs 逐图，实测差 1.8 pt；
    PA 公式写错一次就差 33 pt）；③ **逐图分布 + 最差样本**必须交付（实测 6/112 张 Dice <0.4、
    最差 2 张 0.000 完全漏检，全被均值 0.74 掩盖）。轻量 U-Net 从头训练的参考值：
    416 px / 1.94 M 参数 / 23 分钟 → 批级 Dice 0.7377（见 SKILL.md STEP E5 升级清单）。

  cv2/statsmodels/imblearn 出现在局部 import，缺失时降级路径已在注释给出。
- 溯源题号用于论文素材引用（如「本方法见 2018D 独立解答 §4.2」），
  实战题（盲测集/实战集）不得引用原料文件本身，只复用模板骨架。
